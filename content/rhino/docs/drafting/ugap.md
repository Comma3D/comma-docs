| Menu | Command |
| --- | --- |
| `commaMenu` → **Drafting** | `uGap` |

Reports the min/max gap between two geometries. Pick a point for a local gap, or Enter to bake min/max.

#### Steps

1. Select Source…
2. Select Target…
3. Pick point on Source to measure gap (Enter = bake Min/Max)`.


#### Options

| Option | What it does |
| --- | --- |
| BakeResult / UnitDisplay | Bake and units. |
