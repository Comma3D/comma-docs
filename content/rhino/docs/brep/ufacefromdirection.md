| Menu | Command |
| --- | --- |
| `commaMenu` → **Brep** | `uFaceFromDirection` |

Extracts Brep faces whose normals align with a direction within an angle tolerance.

#### Steps

1. Select brep to extract faces
2. direction points (Enter for Z-axis)
3. Angle tolerance in degrees`.


#### Options

| Option | What it does |
| --- | --- |
| Reverse | No/Yes. |
| BothDirections | No/Yes. |
