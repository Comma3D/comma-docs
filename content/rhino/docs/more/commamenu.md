| Not on `commaMenu`. Type the command name. | `commaMenu` |

Shows a pop-up text menu at the pointer with every Comma command grouped by category. Use it when the Comma menu bar is not visible or from a hotkey.

#### Steps

1. Run `commaMenu`. A text menu opens near the pointer.
2. The first item is `License Manager` (runs `commaRegister`). Below it are the submenus Doc, Curve, Surface, Brep, Mesh, Drafting, CAD and IFC.
3. Open a submenu and click a command. The command runs as `! _<command>`.
4. At the end, `About` shows the `About CommaRh...` dialog and `User Manual`, which opens the manual in the web browser.

commaMenu is also the first item of the uQuickTools menu.
