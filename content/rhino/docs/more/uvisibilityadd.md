Adds more objects to the Comma Visibility panel that was opened with uVisibility. It is normally run from the Add button of that panel.

#### Steps

1. Run `uVisibility` first to open the Comma Visibility panel.
2. Click `Add` in the panel, or run `uVisibilityAdd`. The prompt reads `Select more objects to add.`
3. Select more objects and press Enter (or Esc) to finish.
4. The added objects appear in the panel, where you can use `Hide`, `Isolate`, `Show all`, `Remove`, `Select` and `Clear`.

If the panel is not open the command says `Comma Visibility panel is not open. Run uVisibility first.` The panel lists objects by Layer and Type. Pick a `Key` and a `Value` above the table to narrow the list to the objects that carry that user-text value; the value column is then named after the key.
