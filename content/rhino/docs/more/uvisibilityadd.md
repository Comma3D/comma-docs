| Not on `commaMenu`. Type the command name. | `uVisibilityAdd` |

Adds more objects to the Comma Visibility panel that was opened with uVisibility. It is normally run from the Add button of that panel.

#### Steps

1. Run `uVisibility` first to open the Comma Visibility panel.
2. Click `Add` in the panel, or run `uVisibilityAdd`. The prompt reads `Select more objects to add.`
3. Select more objects and press Enter (or Esc) to finish.
4. The added objects appear in the panel grid, where you can use `Hide`, `Iso`, `Show`, `Remove`, `Select` and `Clear`.

If the panel is not open the command says `Comma Visibility panel is not open. Run uVisibility first.` The panel has a search box (`Search layer, type...`), sync and group toggles, and the columns Object and Vis.
