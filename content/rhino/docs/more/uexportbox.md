| Not on `commaMenu`. Type the command name. | `uExportBox` |

Parallel mesh export of geometry clipped by a closed box.

#### Steps

1. Select clipping box (closed polysurface)
2. then a save-path dialog.


#### Options

| Option | What it does |
| --- | --- |
| Preset | Speed / Quality / Custom. |
| IncludeHidden | No/Yes. |
| Boolean | Off/On. |
