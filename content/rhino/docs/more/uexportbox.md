Where to find it: type `uExportBox`.

Parallel mesh export of geometry clipped by a closed box.

## Options

| Option | What it does |
| --- | --- |
| Preset | Speed / Quality / Custom. |
| IncludeHidden | No/Yes. |
| Boolean | Off/On. |

## Prompts

`Select clipping box (closed polysurface)`; then a save-path dialog.
