| Menu | Command |
| --- | --- |
| `commaMenu` → **Curve** | `uPolyToNurbsCurve` |

Filters polyline vertices by tolerance, then replaces the polyline with a cubic interpolated NURBS curve.

#### Steps

1. Select polyline curves`.


#### Options

| Option | What it does |
| --- | --- |
| Tolerance | Vertex filter tolerance. |
