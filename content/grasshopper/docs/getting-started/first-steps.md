## Use a component

1. Open the **Comma** tab in the Grasshopper ribbon. Components are grouped in panels: Curve, Data, Display, Plane, Point, Surface and Util.
2. Drag a component onto the canvas, or double-click the canvas and type its name or nickname (for example `Divide+`).
3. Hover over an input or output to read its description. Every component of the plugin is also listed in the [component reference](../../components/), with all inputs, outputs and options.

{{% callout type="info" %}}
**Tip.** A component that reports a problem turns orange or red. Click the balloon in its corner to read the message.
{{% /callout %}}

## Tidy a canvas

1. Group some components (**Ctrl+G**) and give the group a name that starts with a prefix, for example:

   ```text
   r_inputs
   ```

2. With Script Organizer's automatic mode on, the group takes the color of its prefix and the wires that leave the group fade.
3. Open **Comma → Settings...** to change the prefix colors or turn the automatic modes off.

See [Script Organizer](../../script-organizer/) for every feature.
