Comma Container (`Comma_GH_Container`) is a snippet library for Grasshopper. Select some components, save them as a **snippet**, and drop a copy on any canvas later, from a button or a search box on the canvas toolbar.

## What you get

At the end of Grasshopper's canvas toolbar, just before the Script Organizer buttons, Comma Container adds:

- a **Comma button** with a dropdown arrow: click the button to save the selected components as a snippet, click the arrow to browse the library;
- a **Search** box that finds snippets by name.

## Terms

| Term | Meaning |
| --- | --- |
| **Snippet** | A set of components saved together. The save dialog calls it a *group*. |
| **Tab** | A folder in the library that holds snippets, for example `Curves` or `Docs`. |
| **Library** | All your tabs and snippets. |

A snippet keeps the components, their settings and their wires, a **description**, and a small **picture** of the canvas taken when you saved it.

## Requirements

Comma Container is built together with [Script Organizer](../script-organizer/) and puts its toolbar items right before Script Organizer's color, wire and opacity buttons, so install both. See [Installing](../getting-started/installing/#comma-container).
