title: Scribble
weight: 4
---

Scribbles turn the name of a group into a label on the canvas.

| Command in **Comma → Scribble** | What it does |
| --- | --- |
| **Label Groups** (Ctrl+Shift+L) | For each selected group, creates a scribble from the group's name, places it at the group's top-left corner and adds it to the group. |
| **Size +** | Increases the font size of the selected scribbles by one step. |
| **Size -** | Decreases the font size of the selected scribbles by one step. |

The font size is limited to the range 5 to 100. Creating, removing and resizing scribbles can all be undone with **Ctrl+Z**.
