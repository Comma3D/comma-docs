## Settings dialog

Open **Comma → Settings...** (the dialog is titled *Comma Settings*).

| Section | Options |
| --- | --- |
| **Color Group** | **Auto**, **Remove Prefix**, **Color Only (no text)**, **Print Log** |
| **Fix Params** | **Auto**, **Print Log** |
| **Fix Wire** | **Auto**, **Print Log** |
| Colors | The canvas color, the panel color, the default group color and the **Prefix Groups** table (prefix and color). **+ Add** adds a prefix, **Defaults** restores the original prefixes. |

Click **OK** to apply and **Cancel** to close without changes. **Print Log** writes what a feature did to the Rhino command line, which helps when something does not behave as you expect.

## Canvas toolbar

At the end of Grasshopper's canvas toolbar you find:

- one **color swatch** per prefix (see [Color Group](../color-groups/));
- the **Default**, **Faint** and **Hidden** wire buttons (see [Fix Wire](../fix-wires/));
- an **Opacity** box that sets the transparency of the Grasshopper window: pick 100%, 70% or 50%, or type your own percentage between 20% and 100%. Press **Esc** to cancel what you typed.

## Keyboard shortcuts

The commands of the **Comma** menu (Run Once, Reset Default, Label Groups, Size +/-, Clear and Internalise Selected Inputs and the Ctrl+Alt toggle) are registered with Grasshopper's keyboard shortcut system, so you can assign your own shortcuts to them in Grasshopper's shortcut settings. **Label Groups** has **Ctrl+Shift+L** by default.
