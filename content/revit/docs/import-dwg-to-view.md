title: "Import DWG to View"
weight: 80
---

**Ribbon** · Comma Rvt → Export → Import DWG to View

Link a DWG as a reference in the active Revit plan, including supported rotated plans.

1. Open the target plan and choose **Import DWG to View**.
2. Browse to the DWG. Review display settings, including **Place in background** and **Pin after linking**.
3. Click **Import DWG** to create the link. Check the reference against a known point in the model.

The link uses shared coordinates and the units declared in the DWG.
