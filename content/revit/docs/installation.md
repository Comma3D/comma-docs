## Before you install

In Revit, open **Help → About** and note the full version, including the update number (for example, **2025.4.4**).
Check the CommaRvt release notes for compatibility with that version.

Revit updates can change the .NET runtime used to load add-ins. An installer that works on another computer may require a different Revit update.
In particular, a .NET 10 add-in cannot run inside a Revit process using .NET 8. Installing .NET 10 separately does not change the runtime used by that Revit version.

## Install

1. Close all running Revit sessions.
2. Open the [Comma releases](https://github.com/Comma3D/comma-docs/releases) and find the relevant **CommaRvt** release.
3. Read its compatibility notes, then download **CommaRvt.exe** from **Assets**.
4. Run the installer. If it lists several Revit versions, select the versions you want to install.
5. Finish the installation and restart Revit.
6. Look for the **Comma Rvt** ribbon tab. Use **License** to complete activation if required.

The **Source code** archives generated by GitHub contain this documentation repository. Use the attached installer to install the add-in.

## Update

Close Revit before running a newer compatible installer. After installation, reopen Revit and check the **Comma Rvt** tab.
Keep a copy of the previous installer if you need to return to an earlier release.

## If Secure Loader fails to start

If Revit reports **“Revit cannot run the external application ‘Comma Revit Secure Loader’”**, first check the full Revit version against the release notes.
The message alone does not identify the underlying cause.

For example, a journal showing **Revit 2025.4.4** and **.NET 8** requires an add-in build compatible with .NET 8, rather than a .NET 10-only build.

If the error remains, [report an issue](https://github.com/Comma3D/comma-docs/issues) and include:

- The full Revit version from **Help → About**.
- The CommaRvt release and installer filename.
- A screenshot of the error and any additional details.
- The journal from the session in which the error occurred.

On Windows, open the following path in File Explorer, replacing `20XX` with the Revit year:

```text
%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals
```
