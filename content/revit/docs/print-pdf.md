weight: 70
---

**Ribbon** · Comma Rvt → Export → Print PDF

Print the current view or a selection of views and sheets through a PDF printer.

1. In **Print Settings**, select a PDF printer and an output folder.
2. In **Print Range**, choose **Current View** or **Selected Views/Sheets**. Review the detected paper sizes for the selected items.
3. Set the naming rule and choose one combined PDF or separate files. Click **PRINT**.
