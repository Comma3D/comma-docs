**Ribbon** · Comma Rvt → Export → Family Manager

Find editable families in the project and rename, export, or delete them in batches.

1. Use **Entire project** or **Pick in model** to define the scope. Filter by family or type name and check the families you want to process.
2. Preview a rename before applying it. Check any name conflicts and decide whether to also rename types whose names match the old family name.
3. To save families as RFA files, choose a destination folder and an existing-file policy. Before deleting families, review the preview of affected elements and confirm the impact.

Checked families can stay selected when a filter hides them. Review the scope and selection before applying a batch.
