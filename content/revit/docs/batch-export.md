---
title: "Batch Export"
weight: 60
---

**Ribbon** · Comma Rvt → Export → Batch Export

Export multiple Revit views or sheets in one operation. Available formats include PDF, DWG, DGN, DWF, IFC, NWC, and images (IMG).

1. Select the output format and choose the views or sheets for the batch. Available items depend on the format.
2. Review the format settings and set the output folder and file naming.
3. Run the export and verify the files in the output folder.
