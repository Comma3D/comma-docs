**Ribbon** · Comma Rvt → General → License

Open **License** to view the License Manager and check your activation status.

- If you already have a key, paste it in **Activate License Key (Offline JWT)** and click **Activate Key**.
- For online activation, fill in the requested details. Use **Sync Existing Key** to look up an existing key or **Send Request** to request one.
- Use **Copy** when support asks for your machine identifier. Use **Remove License** to clear the saved activation on this machine.
