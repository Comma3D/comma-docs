**Ribbon** · Comma Rvt → Export → Link IFC

Link an IFC model and choose where its origin lands in the Revit project.

1. Browse to an IFC file and review **IFC Header Information**.
2. Under **Placement**, choose **Internal Origin**, **Project Base Point**, **Survey Point**, or **Manual Point (Pick)**. In manual mode, enter coordinates or use **Pick Point from Model**.
3. Set a rotation angle if needed, click **Link IFC**, and check the link against a known reference point.
