**Ribbon** · Comma Rvt → Parameter → Check Solid

Inspect element geometry and review calculated solid volumes.

1. Open **Check Solid** and click **Run Check**.
2. Review the **Status** and **Volume (m³)** columns. Use **Errors Only** to focus on flagged elements, **Select in Revit** to locate them, or **Show Error Edges** to inspect the reported geometry.
3. Use **Export Report** to save the results. If you want to write the calculated volume back to the model, use **Apply Volume** and review the target parameter before applying.
